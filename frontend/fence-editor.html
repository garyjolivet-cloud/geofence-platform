Per-zone handles (selected zone only)
Bearing (amber) — arrow tipDrag in a circle to set the direction the visitor should face on arrival. Default east (90°).
Reveal radius (green) — eastCircle zones only. Drag to resize the filled zone circle.
Audio fade (blue) — southDrag to set the distance at which zone audio starts fading in. Shown as a blue dotted ring.
Full volume radius (dark purple) — SEDrag to set this stop's inner radius where audio plays at full volume. Always smaller than the audio fade distance. Leave untouched to use the project default.
Fade gradient (purple haze)Fills the space between the audio fade ring and full volume. Solid = 100% volume, fading to clear = where audio starts.
Polygon vertex (white square)One handle per corner. Drag to reshape the polygon.
Tripline endpoint (cyan)Two handles, one at each end. Drag to reposition a crossing line.
Project-wide handles (any selected zone)
Visitor bubble (cyan dashed) — SWDrag to set the simulated visitor position radius used in the test simulator.
